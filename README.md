# Leaf 1.1 · 阅读词典

双击 **Leaf.exe** 即可使用。免费、完全离线，不需要账号；查词和复习都在本机完成，不调用任何模型或网络服务。

> 仓库里不含打包好的 Leaf.exe。克隆后可以直接 `python app.py` 运行（需要 Python 3.11+，Windows 读音用系统自带语音），或者运行 `build.ps1` 自己打包（需要先安装 PyInstaller）。

请让 Leaf.exe 和旁边的 `data`、`user_data` 文件夹待在一起；两个大词库放在 `data` 里，不打包进 exe。

## 怎么用

- **查词**：输入单词，实时出现候选词，用 ↑↓ 选择、回车查询。你生词本里的词排在最前面。
- **带原句查**：粘贴一句或一段原文，它会放进“阅读原句”，点句中的词即可查询。收录时一并保存原句。
- **收录**：点“加入生词本”或按 `S`，不自动收录。收错了可以在提示里点“撤销”。
- **我的释义**：查词、复习和已有词条都支持“用自己的话改写”，保存后各处统一使用，也可恢复原释义。
- **每日进度**：显示“今日已学 / 目标”。每个词当天只计一次，无论回答是否正确；答错不会让进度倒退，撤销评分会还原记录。首次学习、复习旧词和总练习次数分别显示；回忆表现按每个词今天的最近回答统计。
- **继续学习**：每日目标不是上限。到期词和计划内新词学完后，可点“再学 10 个新词”，一轮轮继续，直到没有未学词。加学只影响今天；同一次请求重试不会重复增加名额。
- **复习**：按 `R` 开始，先回忆，按空格翻开答案，再按 `1` 不记得、`2` 费力想起、`3` 记得。`Ctrl+Z` 可撤销刚才的评分。
- **生词本**：每页 40 个词，按需加载。支持搜索、排序、状态筛选。点一个词，可查看完整释义、复习记录和模型估计的记忆强度，也可暂停或移除。

## 复习是怎样安排的

- **一条队列**：到期的学习 / 重学词优先，其次到期旧词，最后计划内新词。无需手动切换“新词”和“复习”。
- **每日新词计划**：默认每天自动安排 10 个新词，设为 0 时只复习已有词；仍可以在完成页手动加学。已到期旧词不受每日目标或新词计划限制。
- **按实际间隔复习**：使用 FSRS-6，学习步骤为 1 分钟 / 10 分钟，重学步骤 10 分钟；实际下次时间由评分和卡片状态决定。取消原来的自动提前学习，未到时间不会重新出题。等待时可以加学新词，到期后会自动显示。
- **三档评分**：不记得、费力想起、记得，对应 FSRS 的 Again / Hard / Good。看了答案才想起来就选“不记得”；系统决定下次时间。旧版“轻松”记录按“记得”统计。
- **可选拼写填空**：新词先练看词想意思，熟悉后交替练看句子写词。关闭“拼写填空”后，只练看词想意思。填空在阅读原句、自己的造句和词典例句间轮换。
- **学习日**：统一按本机凌晨 4 点划分。统计、新词计划、加学名额和连续天数使用同一边界。连续天数按达到最低目标的天数计算。

调度器的目标记住率默认 90%，可调整为 85% / 90% / 95%。较高目标通常带来更频繁的复习；这是模型用于安排间隔的目标，不是实际测试成绩，也不保证每个人都达到该比例。实现依据 [py-fsrs 官方项目](https://github.com/open-spaced-repetition/py-fsrs)，目标参数说明见 [Anki 官方文档](https://docs.ankiweb.net/deck-options.html#desired-retention)。

“学习记录与安排”显示未来七天已学词的到期分布。今天稍后到期的词单列，未学词不混入预测。它是当前安排，会随回答、加学和暂停更新。

近 30 天延迟回忆成功率只统计间隔至少一天的看词回忆，同词同日取第一次。短时重复和拼写填空不混入这个指标，并显示样本数。

先尝试回忆再看答案、隔一段时间再回忆，是检索练习和间隔练习的应用。FSRS 负责个体词条的时间安排；界面的每日目标用于维持学习习惯，不干预记忆参数。

## 你的数据

- 个人数据在 `user_data/learning.sqlite3`。首次迁移时会在 `user_data/backups` 中保存升级前副本。
- 1.1 保留原始评分、复习时间、个人释义和设置，不重排旧卡片；历史进度图改按当天学过的不同词数展示。
- 导入的大批旧词按每日新词计划逐步进入学习，不会一次全部算作到期旧词。
- 设置中可导出或导入完整备份；合并时优先保留本机已有进度和个人释义。
- 关闭窗口后服务仍在后台，下次打开更快；设置里可以彻底退出。

## 词库

学习词库收录 84,236 条中文词条，基于 Open Dictionary v2.0（Wiktionary / Wiktextract），并做过本地修订；缺词时用 ECDICT 中文简释补充，界面显示实际来源。整库结构检查不等于逐条人工审定，审校记录见 [reviews/](reviews/README.md)。数据按 CC BY-SA 4.0 共享，详见 `licenses/`。

## 开发与验证

```powershell
python app.py
python -m unittest discover -s tests -v
node --test tests/test_requests.cjs tests/test_study.cjs
python tests/packaged_smoke.py
powershell -ExecutionPolicy Bypass -File build.ps1
```

测试使用临时数据，不更改真实生词本。重点覆盖：达标后继续学习、严格到期、重复请求、同词去重、撤销恢复、跨天边界、未来到期分布、填空开关、分页、备份与释义保存。

- `app.py`：本地服务、复习调度、统计和生词本。
- `dictionary_engine.py` / `learner_dictionary.py`：释义呈现。
- `offline_speech.py`：Windows 本机语音。
- `web/`：界面、请求管理和纯学习逻辑。
- `scripts/build_learner.py`：从已校验的发布包和修订内容重建词库。
