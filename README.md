# Leaf 1.0 · 阅读词典

双击 **Leaf.exe** 即可使用。免费、完全离线，不需要账号；查词和复习都在本机完成，不调用任何模型或网络服务。

> 仓库里不含打包好的 Leaf.exe。克隆后可以直接 `python app.py` 运行（需要 Python 3.11+，Windows 读音用系统自带语音），或者运行 `build.ps1` 自己打包（需要先 `pip install pyinstaller`）。

请让 Leaf.exe 和旁边的 `data`、`user_data` 文件夹待在一起：两个大词库放在 `data` 里，不再打包进 exe，所以启动很快（约 0.7 秒，以前约 2 秒）。

## 怎么用

- **查词**：输入单词，会实时出现候选词，用 ↑↓ 选择、回车查询。你生词本里的词排在最前面。
- **带原句查**：在查词框里直接粘贴一句或一段原文，它会自动放进“阅读原句”，然后点句中的任意一个词就能查。原句会和单词一起收录。
- **收录**：点“加入生词本”或按 `S`。收错了可以在提示里点“撤销”。
- **每日目标**：首页、侧栏和复习页都显示“今天记住 / 目标”，例如 12 / 30。只有答“费力想起”或“记得”的词才算记住；答“不记得”的词会在稍后重新出现，等你想起来才计入。同一个词一天只算一次，以当天最后一次的回答为准。首页同时列出今天复习了多少个词，以及记得、费力想起、不记得各有几个。进度条上的竖线是最低目标（默认 8 个）：没到最低目标时进度条是橙色，过了最低目标变浅绿，完成目标变深绿，跨过这两个点时还会弹出提示。连续天数按“达到最低目标”的天数计算。到期的词不够完成目标时，复习完成页可以一键加学新词补足。
- **复习**：按 `R` 开始。先回忆，按空格翻开答案，再按 `1` 不记得、`2` 费力想起、`3` 记得。按 `Ctrl+Z` 可以撤销刚才的评分。
- **生词本**：可以搜索，也可以按待复习、新词、学习中、已掌握、常忘、已暂停筛选。点任意一个词，可以查看完整释义、复习记录和记忆强度，也可以暂停或移除。
- **我的释义**：任何释义旁都有“用自己的话改写”。用自己的话解释一遍，本身就是很有效的记忆方法。

## 复习是怎样安排的

每一项设计都对应有研究支持的学习原理：

| 做法 | 原理 |
|---|---|
| 先回忆，再看答案 | 检索练习效应：主动回忆比反复阅读记得更牢（Roediger & Karpicke, 2006） |
| FSRS-6 间隔重复，默认目标记住率 90% | 间隔效应（Cepeda 等, 2006）；FSRS 为每个词估算遗忘曲线（Ye 等, 2022） |
| 新词先练“看词想意思”；记牢后（稳定性 ≥ 3 天）交替练“看句子和中文，写出这个词” | 从认识到会用：产出型回忆更能迁移到实际使用（Nation, 2013；Laufer & Goldstein, 2004） |
| 填空句子在你的原句、你的造句和词典例句之间轮换 | 换着语境练，有助于形成可迁移的理解 |
| 翻开答案后可以“用它造个句子”，造的句子会用于以后的填空 | 生成效应：自己产出的内容记得更好（Slamecka & Graf, 1978） |
| 每天新词设上限（默认 10 个），到期复习不设上限 | 避免一次涌入太多新词，造成越积越多的复习负担 |
| 新词与复习穿插出现（约 1 个新词配 3 个复习） | 穿插练习 |
| 刚学的词隔 1 分钟、10 分钟再回忆；同一个词不会紧接着出现两次 | 短时间隔同样有效 |
| 一个词忘了 5 次，会建议你改写释义或造句 | 处理“顽固词”：重新编码比重复看更有效 |
| 学习日从凌晨 4 点开始计算 | 熬夜读书时，复习仍算在“今天” |

评分只有三档：不记得、费力想起、记得（对应 FSRS 的 Again / Hard / Good）。FSRS 的第四档“轻松”已去掉：它是最不可靠的自我判断，少一个选项也能答得更快。以前选过“轻松”的记录按“记得”统计。

请诚实评分：看了答案才想起来，就选“不记得”。高估记忆会让间隔拉得太长，每日目标也会虚高。

**设置里可以调整**：每日目标和最低目标（1–500，最低目标不会超过每日目标）、每日新词数（0–100）、目标记住率（85% / 90% / 95%，越高复习越频繁）、是否开启拼写填空、外观（自动 / 浅色 / 深色）、读音口音。

## 你的数据

- 个人数据在 `user_data/learning.sqlite3`。1.0 第一次启动时，会在 `user_data/backups` 里自动保存一份升级前的副本。
- 原有的生词、原句、复习进度和我的释义全部保留。导入的 900 多个旧词会按每日新词上限逐步进入复习，不会一下子全部到期。
- 设置里可以导出或导入完整备份。导入时，本机已有的复习进度和个人释义优先。
- 关闭窗口后服务仍在后台运行，下次打开更快；设置里可以彻底退出。

## 词库

学习词库收录 84,236 条中文词条，基于 Open Dictionary v2.0（Wiktionary / Wiktextract），并做过本地修订；缺词时用 ECDICT 中文简释补充，界面会显示实际来源。整库结构检查不等于逐条人工审定，审校记录见 [reviews/](reviews/README.md)。数据按 CC BY-SA 4.0 共享，详见 `licenses/`。
